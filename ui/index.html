    1

    选择凭证配置

    一个 JumpServer 可保存多组数据库凭证配置。每个配置独立记住组织、数据库、系统账号和目标 DBX 连接；切换后即可一键刷新，不会保存临时密码。

    2

    选择数据库

    支持 MySQL、MariaDB、PostgreSQL 和 SQL Server。找不到数据库时，请检查组织和“应用 / 资产”类型。

    3

    填入 DBX 连接

    将打开 DBX 的新建连接表单，填入代理主机、端口和临时凭证。

    每个配置会自动保存当前选择。切换配置后点击一次即可刷新；请先关闭已打开的连接编辑窗口，再填入并保存。

    配置

    本次连接参数

    Web / Docker 可在此复制参数；自动填入需要插件和 DBX 桌面版运行在同一台电脑。

    令牌有效期内可连接。过期后重新刷新凭证，并在 DBX 中重新连接数据库。
